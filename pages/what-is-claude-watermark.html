What Is Claude's Invisible Text Watermark?

Claude's invisible text watermark refers to the mechanism Anthropic applies so that text generated by Claude carries a statistically detectable, human-invisible marker. This page explains it in plain English using publicly available information.

Definition

An invisible watermark is a pattern embedded into generated text—not visible to readers—that is designed to be detectable by a corresponding classifier. [待确认: exact public definition; cite Claude Help Center]

Why It Exists

The stated purpose is to help distinguish AI-generated text from human text for transparency and safety. [待确认: cite official rationale]

How It Differs From Detectors

Watermarking embeds a signal at generation time; detectors try to classify text after the fact. They are related but distinct. This site does not claim to bypass or remove either.
